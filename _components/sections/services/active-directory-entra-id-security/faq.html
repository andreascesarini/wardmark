Frequently asked questions

Can we review Active Directory and Microsoft Entra ID together?

Yes. A hybrid review can cover both environments, including how identities are synchronised and where administrator access is managed. It can also focus on a specific directory, tenant or set of privileged accounts.

Can you work from an assessment we already have?

Yes. Andreas can review the findings with your team, check which ones are still relevant and help you decide what to address first. Implementation can be included in the agreed scope.

What if a change affects how an application signs in?

Andreas works with the application owner to understand the dependency and plan when the change can be made. If several applications need to move to a different sign-in setup, the work can be scoped as part of identity architecture and migration.

How do we keep administrator permissions under control after the review?

Clear ownership helps your team manage the grants, role changes and exceptions that come up after the work is done. Access governance can define who approves privileged access, when it’s reviewed and how those decisions are recorded.
