Frequently asked questions

Can we start with one agent or workflow?

Yes. The work can focus on a single use case and the systems or data it needs. Your team can use what it learns when reviewing access for other agents.

What if we already have an agent connected to business systems?

Andreas can review the identity the agent uses and compare its current permissions with the work it’s meant to do. Your team can then decide which access to keep, reduce or remove.

How does this fit into our existing access reviews?

Your access governance process can cover agents alongside employees and service accounts. The scope can define who reviews an agent’s permissions and what should trigger a review, such as a change to the agent’s job.

What if the agent depends on systems we already need to harden?

An Active Directory and Entra ID security review can help you see which accounts and permissions the agent would rely on. You can then prioritise any changes that need to happen before rollout.
