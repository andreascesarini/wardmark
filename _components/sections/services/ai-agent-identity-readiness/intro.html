Start with the work the agent will do

If an agent will summarise supplier invoices, the finance team needs to decide which records it can read and who can approve access to more records if the task changes. Those decisions are easier to make while the team is planning the workflow.

  • Identity. Decide which identity the agent will use and how your team will recognise its activity.
  • Permissions. Specify which systems and data the agent can access and which actions it can take.
  • Ownership. Name who is responsible for the agent’s access and who can approve, review or remove it.
  • Traceability. Decide what needs to be recorded so your team can see what the agent did and why it had access.
